# Sky Sprint

A simple HTML5 2D side-scroller platform game built with plain JavaScript and Canvas.

## Features
- Gravity and jumping physics
- Side-scrolling camera
- Platforms and level progression
- Enemy patrols and stomp mechanic
- Win condition at the flag
- HUD for lives and score

## Run locally
1. Open `index.html` in a browser, or
2. Serve the folder with a local web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Controls
- Move: A/D or Left/Right Arrow
- Jump: W or Up Arrow or Space

## Goal
Reach the flag at the far right of the level while avoiding enemies.
